# 线上问题：按日期查订单「漏单 / 串单」

报告人：客服主管、产品。所有时间都是北京时间（用户和客服都在国内）。

## 现象
最近客服和用户反馈，按日期看订单时，有的单「不见了」，有的单「跑到别的日子里」。

### 案例 1（管理后台，客服）
- 11-17 上午，客服在后台订单列表选日期 **2026-11-16** 查订单，找不到订单 **O-1001**
- 用户说他是 **11-16 凌晨 02:13** 下的单
- 客服换成 **2026-11-15** 查，反而看到了 O-1001

### 案例 2（App「今日订单」）
- 用户 **11-17 07:05** 下单 **O-1002**
- **09:12** 打开 App「今日订单」，看不到这一单（「全部订单」里能看到）

### 案例 3（App「今日订单」）
- 用户 **11-16 01:20** 打开 App「今日订单」，看到了**前一天 21:40** 下的订单 **O-1003**，以为是重复下单

## 时间线
- 11 月 3 日之后客服反馈明显变多
- 8 月下旬也零星有过「凌晨在今日订单里看到昨天的单」的反馈，当时没有复现，就搁置了

## 影响
- 客服按日期核对订单出错；运营日报（每日订单数、成交额）数字被质疑
- 用户以为订单丢了或者重复扣款
